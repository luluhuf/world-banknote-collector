WORLD BANKNOTE COLLECTOR — PREMIER PROTOTYPE

Ce dossier contient une première base PWA :
- interface mobile bleu nuit et doré
- catalogue initial de pays et quelques territoires
- ajout manuel d'un billet avec photo
- sauvegarde locale sur l'appareil via IndexedDB
- consultation hors connexion après première visite et mise en cache

LIMITES IMPORTANTES DE CETTE VERSION :
- ce n'est pas encore une application publiée sur l'App Store
- reconnaissance automatique par IA non intégrée
- pas encore de synchronisation cloud entre appareils
- les fiches historiques détaillées et le catalogue numismatique vérifié restent à construire
- les données locales peuvent être perdues si les données du site sont effacées ; faire une sauvegarde avant tout nettoyage Safari

INSTALLATION :
1. Héberger les fichiers sur un site HTTPS (par exemple GitHub Pages).
2. Ouvrir l'adresse dans Safari sur iPhone.
3. Partager > Sur l'écran d'accueil > Ajouter.
4. Ouvrir ensuite depuis l'icône.
